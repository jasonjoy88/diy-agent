## Phase 任务说明速查

### Phase 1 → codebase-scout

```
任务：对仓库「{路径}」进行广泛初步勘察，生成分析摘要。
模式：初步勘察
覆盖：定位与作用、技术栈、目录骨架、入口、环境/配置线索、外部依赖、启动线索
产出：500-1000 字摘要 + 证据池（≥10 条路径）
```

### Phase 2 → architecture-planner

```
任务：基于初步勘察摘要，规划项目分析报告章节大纲。
约束：完整 max_sections=6（可用默认六维）；快速=3；不含引言/结论/证据索引
产出：JSON { "title", "date", "sections", "rationale" }
```

### Phase 3.1 → codebase-scout

```
任务：对「{章节标题}」深度勘察并撰写章节草稿。
模式：深度勘察
要求：优先复用证据池；关键断言附 `path` 引用；800-1500 字；含「一句话结论」与「建议先看的文件」
产出：草稿 + 本章新增证据清单
```

### Phase 3.2 → draft-reviewer

```
任务：审查「{章节标题}」草稿。
current_round = {N} / 3
6 维：证据充分性 / 事实准确性 / 范围完整性 / 内容深度 / 结构清晰度 / 上手友好度
产出：PASS 或 REVISE；第 3 轮强制 PASS + 遗留建议
```

### Phase 3.3 → draft-reviser

```
任务：按审稿意见修订「{章节标题}」草稿。
要求：逐条回应；禁止编造路径；未批评部分不动；缺证据标待确认
产出：完整修订稿 + 修改说明
```

### Phase 4 → report-writer

```
任务：汇总各章撰写引言/结论/目录/证据索引（JSON）
引言与结论各 200-400 字，须含路径引用；结论含上手建议
```

### Phase 5 → report-publisher

```
任务：整合终稿 + Final QA；不改分析内容
```
