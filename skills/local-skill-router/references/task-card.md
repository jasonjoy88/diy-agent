# 任务解析卡

检索之前先填这张卡。形态没判对，后面的图谱查询会偏。

```json
{
  "task": "用户原话，一字不改地保留",
  "task_type": "正式方案类文档",
  "deliverable_forms": ["word", "ppt"],
  "domain": "水务",
  "audience": "客户方决策层",
  "keywords": ["建议书", "报价", "水质监测"],
  "constraints": ["正式可呈报", "含数据表格"],
  "quality_bar": "领导呈报级"
}
```

| 字段 | 必填 | 说明 |
|---|---|---|
| `task` | 是 | 用户原话。不要改写 |
| `task_type` | 强烈建议 | 记忆用的分类键，必须用下面的命名表 |
| `deliverable_forms` | 否 | 只能用 13 个标准键，不许自造 |
| `domain` | 否 | 行业或技术领域 |
| `audience` | 否 | 决定质量线 |
| `keywords` | 强烈建议 | 3–6 个最有区分度的名词，不要整句丢进去 |
| `constraints` | 否 | 硬约束，给人复核，不参与打分 |
| `quality_bar` | 否 | 什么算合格 |

## 交付形态（13 个）

| 键 | 触发词 |
|---|---|
| `word` | word、文档、报告、docx、公文、合同、标书 |
| `ppt` | ppt、pptx、幻灯片、演示、汇报材料、讲标、路演 |
| `excel` | excel、xlsx、表格、报表、清单、台账、测算表 |
| `pdf` | pdf、电子书、画册 |
| `html` | 网页、html、落地页、看板、官网、专题页 |
| `code` | 代码、脚本、写个程序、接口、重构、自动化 |
| `chart` | 图表、可视化、看板、仪表盘、数据图 |
| `map` | 地图、gis、地理 |
| `image` | 图片、海报、封面、配图、插图、logo |
| `video` | 视频、短视频、成片、分镜、剪辑 |
| `audio` | 音频、配音、播客、音效、语音合成 |
| `3d` | 3d、三维、立体模型、建模 |
| `research` | 调研、研究、竞品、行业分析、尽调 |

主动补隐含形态：「报给领导」= word + ppt；「发抖音」= video + image；「投标」= word + ppt + excel。

信息不足时先问两句再检索：最后交成什么形式，给谁看。

## 任务类型命名表

| 任务类型 | 覆盖范围 |
|---|---|
| 正式方案类文档 | 建议书、立项书、投标技术文件 |
| 汇报演示类文档 | 幻灯片、讲标稿、路演材料 |
| 数据处理类任务 | 表格清洗、合并、透视、统计 |
| 行业/竞品研究 | 调研报告、竞品分析、尽调 |
| 站点与小程序交付 | 官网、落地页、小程序从 0 到 1 |
| 创意内容生产 | 短视频脚本、海报、文案、分镜 |
| 工程改造与排障 | 重构、迁移、升级、事故处置 |
| 数据可视化与图表 | 看板、图表、地图 |
| 日常办公自动化 | 批量处理、格式转换、文档搬运 |

没在表里的类型，归到最接近的一项，不要自造同义词。
